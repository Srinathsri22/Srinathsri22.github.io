The Problem

Speed to revenue on owned properties

GrowthFusion needed its own lead generation properties (O&O sites) rather than relying entirely on third-party affiliate offers. Each property needed to be production-ready with full tracking, API integrations, and cloud infrastructure. Speed to revenue was critical.

What I Built

HouseCrew

housecrew.com — 18-page site (1 Homepage + 17 Service Pages) built in 4 days.

  • Full Thumbtack API integration (staging + production). Tested all endpoints via Postman, implemented lead routing.
  • GTM setup with 100% conversion tracking coverage across all 18 pages
  • GCP hosting with CI/CD pipeline. Zero downtime since launch.
  • Postback automation: fully automated pipeline from Thumbtack to RedTrack. Every conversion tracked in real time, zero manual steps.
  • Custom performance dashboard consolidating Meta, RedTrack, and Thumbtack data into a single view.
  • 4 services live with active ad spend. Platform expansion to TikTok, Google, Snap, Newsbreak in pipeline.

BathRemodelHub

Complete site with Thumbtack integration, GTM, GCP/CI-CD, and postback automation. Production-ready with zero additional dev work needed on go-live.

QuickHomeFix

quickhomefix.pro — Full platform build: new design, frontend flow, HTML migration from React JSX.

  • Dashboard integrating RedTrack, Meta Ads, LeadProsper, and Thumbtack data with ClickHouse tables and backend APIs
  • 6 buyers onboarded into production: OneHome, RemodelWell, Bath Experts, LeadVision, Exact Customer, Modernize
  • Full buyer management: LeadProsper setup, test lead validation, ZIP code coverage mapping, rejection issue resolution
  • A/B testing for question flow and thank-you pages. Users progressed from low engagement to 6 completed funnel sections.
  • Performance dashboard with campaign-wise and date-wise tracking for leads, sold rate, LP views, and LP CTR

QHF Media Diagnosis & Rebuild

When QHF experienced a sharp CPL regression ($24–32 to $68–98 overnight), I ran a full diagnostic:

  • Pulled 14-day campaign, ad, and daily trend data via Windsor.ai
  • Identified single creative dependency: one ad (VLAD3) accounted for 51% of all spend and was the only viable creative at $27.78 CPL
  • Produced a 10-section media rebuild plan: 3-campaign structure ($80/day BT flagship + $50/day LAL + $30/day creative test), attribution fix, geo targeting, budget plan, kill/scale rules, and 30-day execution roadmap
  • Paused all existing campaigns and rebuilt from zero

Attribution Architecture

  • Proactive postback verification established as team standard: zero postback failures since adoption
