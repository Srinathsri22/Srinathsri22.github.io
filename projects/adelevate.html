The Problem

Manual ops across 4+ ad platforms

Media buyers were managing campaigns across Meta Ads Manager, Snapchat Ads Manager, TikTok Business Center, and Google Ads — plus RedTrack for attribution. They spent hours switching between dashboards, manually monitoring performance, and making repetitive bid/budget changes.

There was no automation, no unified view, and no programmatic loss control. When something broke at 2am, nobody caught it until morning.

What I Built

Rules Engine

A rule-based automation system that manages campaigns across Meta, Snapchat, TikTok, and Google without manual intervention. Supports 5 operation types: pause, activate, budget change, bid adjustment, and dayparting.

Rules operate at campaign, ad set, and ad levels across all platforms simultaneously. The engine continuously evaluates real-time metrics from connected ad platforms and executes spend decisions 24/7.

  • Grew from zero adoption to 150+ active rules within one quarter
  • Manager escalations related to automation failures dropped to zero after an architectural fix resolving a critical API rate-limit issue

Campaign Operations Dashboard

Unified campaign management consolidating 5 platforms and 48 ad accounts (32 Meta + 16 Snapchat) into a single interface.

  • Inline budget controls — increase/decrease by % or fixed amount, daily/lifetime
  • Bid strategy switching — 4 Meta strategies, 3 Snap strategies
  • Pause/resume at campaign, ad set, and ad levels
  • Sort by 20 performance metrics
  • Filter by any of 48 ad accounts, media buyer tag, status, and platform
  • Bulk operations — select multiple campaigns, apply changes in one action
  • Server-side pagination — 25 campaigns/50 ads per page, ~5 second load

Infrastructure

ClickHouse Materialized Views pre-aggregate metrics at every level for sub-second query response. Self-hosted Airbyte ETL on in-house infrastructure, replacing a paid cloud service and saving $1,000+/month.

RBAC & Access Control

3-tier permission model (User / Admin / SuperAdmin) with per-user platform restrictions stored in Supabase. Self-serve ad account provisioning and rules access control without engineering involvement.

  • 48 ad accounts under self-serve RBAC
  • Firestore real-time listeners on rules for instant change propagation

Roles and configuration

  • 500ms debounce on all search/date inputs
  • AbortController request cancellation on 100% of API calls
  • 7+ useMemo / 4+ useCallback optimizations in the campaigns table

Meta API Rate-Limit Fix

Identified the root cause of API rate-limit failures that were blocking the entire ED vertical from scaling. Redesigned the Meta data ingestion architecture with intelligent batching and throttling.

  • 80% reduction in API calls to Meta
  • Unblocked the media buying team and eliminated missed optimization windows
