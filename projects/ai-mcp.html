The Problem

Too many dashboards, too many tabs

Media buyers and managers spent significant time navigating between ad platform dashboards and internal analytics tools to query campaign data, check performance, and take actions.

Simple questions like "what's the CPL on QHF bath campaigns this week?" required opening multiple tabs, applying filters, and cross-referencing data.

What I Built

3 Custom MCP Servers

01

ClickHouse MCP

Direct database querying via natural language. Team can ask questions about campaign performance, spend, revenue, and attribution data without writing SQL or opening dashboards.

02

Meta Ads Manager MCP

Campaign management and data retrieval from Meta's Marketing API through Claude. Read and act on campaign data conversationally.

03 — PROPRIETARY

Snapchat Ads Manager MCP

Built entirely from scratch. No third-party solution exists for Snapchat MCP integration. Self-hosted on Mac Mini infrastructure. The only Snapchat MCP server in production anywhere.

Capabilities

All three servers integrated with Claude AI, enabling the team to:

  • Query cross-platform campaign data in natural language
  • Pull performance reports without navigating dashboards
  • Execute campaign actions (with appropriate safeguards) through conversational interface
  • Cross-reference internal ClickHouse analytics with platform-reported metrics
Impact

Query time for campaign data went from minutes of tab-switching and filter-applying to seconds of natural language conversation. Used daily by the operations team.
